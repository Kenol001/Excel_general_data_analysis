# Excel Data Analysis Projects

## Project Overview

This repository showcases practical data analysis projects using Microsoft Excel, focusing on data cleaning, transformation, analysis, and interactive dashboard development.

## Repository Structure

The repository is organized into three main folders:

 Folder               Description                                                                                                        
 [a_datasets](https://github.com/Kenol001/Excel_general_data_analysis/tree/main/a_datasets)  Contains the raw and cleaned datasets for both projects.                                                           
 [b_data_cleaning](https://github.com/Kenol001/Excel_general_data_analysis/tree/main/b_data_cleaning) Contains Excel workbooks demonstrating the data cleaning and standardization processes for both datasets.         
 `c-dashboards/`      Contains an Excel workbook featuring interactive dashboards for Industrial Logistics and Manufacturing Production. 

The projects cover two business areas:

### 1. Industrial Logistics and Distribution

* Cleaned and standardized raw datasets.
* Removed duplicate records and standardized data formats.
* Created calculated columns for order values, delivery status, and transportation costs.
* Developed an interactive dashboard to analyze material distribution, transportation costs, and delivery performance.

### 2. Manufacturing Production Operations

* Cleaned and transformed production datasets.
* Created calculated columns for production costs, accepted units, and operational performance.
* Developed an interactive dashboard to monitor production output, production costs, quality, and plant performance.
